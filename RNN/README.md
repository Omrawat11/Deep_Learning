# RNN — Recurrent Neural Networks

Part of the [Deep_Learning](https://github.com/Omrawat11/Deep_Learning) repository, this folder covers Recurrent Neural Network architectures and their applications in sequence modeling and NLP — from core theory to practical implementations like sentiment analysis and next-word prediction.

## 📂 Contents

| Notebook | Description |
|---|---|
| `RNN~ Architecture.ipynb` | Core concepts and architecture of Recurrent Neural Networks — how RNNs process sequential data and maintain hidden states. |
| `integer~encoding~simplernn.ipynb` | Text preprocessing with integer encoding, feeding sequences into a Simple RNN. |
| `sentiment-analysis-embedding.ipynb` | Sentiment analysis using an Embedding layer combined with RNN layers. |
| `Deep_RNN.ipynb` | Stacked (multi-layer) RNN architecture for learning more complex sequential patterns. |
| `Bidirectional_RNN.ipynb` | Bidirectional RNNs that process sequences in both forward and backward directions for richer context. |
| `Next_word_predi_LSTM.ipynb` | Next-word prediction using LSTM (Long Short-Term Memory) networks. |

## 🧠 Topics Covered

- RNN fundamentals & hidden state mechanics
- Text preprocessing (integer/word encoding)
- Word embeddings for NLP tasks
- Simple RNN vs Deep (stacked) RNN
- Bidirectional RNNs
- LSTM for sequence generation
- Sentiment analysis
- Next-word prediction (language modeling)

## 🛠️ Tech Stack
