# Deep Learning 🧠

A collection of deep learning implementations covering the three foundational neural network architectures — **ANN**, **CNN**, and **RNN** — built while learning and practicing core deep learning concepts as part of my AI/ML journey.

## 📂 Repository Structure

```
Deep_Learning/
├── ANN/    # Artificial Neural Networks
├── CNN/    # Convolutional Neural Networks
└── RNN/    # Recurrent Neural Networks
```

### 🔹 ANN — Artificial Neural Networks
Implementations of fully-connected feedforward neural networks, covering the basics of forward propagation, backpropagation, activation functions, and training on structured/tabular data.

### 🔹 CNN — Convolutional Neural Networks
Implementations focused on image data — convolution, pooling, and fully connected layers for tasks like image classification and feature extraction.

### 🔹 RNN — Recurrent Neural Networks
Implementations for sequential data, exploring how RNNs (and variants like LSTM/GRU where applicable) handle time-series and sequence-based problems.

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** TensorFlow / Keras / PyTorch, NumPy, Pandas, Matplotlib
- **Environment:** Jupyter Notebook

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Omrawat11/Deep_Learning.git
   cd Deep_Learning
   ```
2. Install dependencies
   ```bash
   pip install numpy pandas matplotlib tensorflow scikit-learn
   ```
3. Navigate to the folder of interest (`ANN`, `CNN`, or `RNN`) and run the notebooks/scripts.
