 # Deep Learning 🧠

A collection of deep learning implementations covering the three foundational neural network architectures — **ANN**, **CNN**, and **RNN** — built while learning and practicing core deep learning concepts as part of my AI/ML journey.

```

│   ├── use pretrained model/

```

### 🔹 ANN — Artificial Neural Networks
Implementation of a fully-connected feedforward neural network (`Ann Proj-1.ipynb`), covering the basics of forward propagation, backpropagation, activation functions, and training on structured/tabular data.

### 🔹 CNN — Convolutional Neural Networks
Implementations focused on image data — convolution, padding, stride, pooling, LeNet architecture, transfer learning with pretrained models, feature-map visualization, and a Cat vs Dog image classification project. See [`CNN/README.md`](./CNN/README.md) for details.

### 🔹 RNN — Recurrent Neural Networks
Implementations for sequential data — RNN architecture fundamentals, integer encoding, embeddings for sentiment analysis, deep (stacked) RNNs, bidirectional RNNs, and LSTM-based next-word prediction. See [`RNN/README.md`](./RNN/README.md) for details.

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** TensorFlow / Keras, NumPy, Pandas, Matplotlib
- **Environment:** Jupyter Notebook

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/Omrawat11/Deep_Learning.git
   cd Deep_Learning
   ```
2. Install dependencies
   ```bash
   pip install numpy pandas matplotlib tensorflow scikit-learn jupyter
   ```
3. Navigate to the folder of interest (`ANN`, `CNN`, or `RNN`) and run the notebooks.
   ```bash
   jupyter notebook
   ```
